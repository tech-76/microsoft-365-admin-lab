# Microsoft 365 Admin Lab

## Overview

This repository documents Microsoft 365 administration and support concepts commonly used in IT Support, Service Desk, Desktop Support, and Junior Systems Administrator roles.

The goal of this lab is to demonstrate practical understanding of user account support, password resets, Outlook troubleshooting, MFA support, mailbox issues, Microsoft Teams basics, licensing concepts, and clear technical documentation.

## Skills Demonstrated

- Microsoft 365 admin support concepts
- User account management documentation
- Password reset and account recovery workflows
- Outlook and mailbox troubleshooting
- MFA support and reset documentation
- Microsoft Teams support basics
- Licensing and access troubleshooting
- Help desk ticket documentation
- User-focused troubleshooting communication

## Repository Structure

| Folder | Purpose |
|---|---|
| `docs/` | Technical notes and support documentation |
| `checklists/` | Step-by-step troubleshooting checklists |
| `tickets/` | Realistic help desk ticket examples |

## Example Support Areas

- User cannot sign in
- Password reset request
- MFA device changed or lost
- Outlook not opening
- Outlook profile issue
- Shared mailbox access issue
- User missing Microsoft 365 license
- Teams audio/video issue

## Disclaimer

This is a learning and documentation lab. It does not contain real user data, company data, credentials, or private information.
