# Microsoft 365 Admin Lab

## Overview

This repository documents Microsoft 365 administration and support concepts commonly used in IT Support, Service Desk, Desktop Support, Technical Support, and Junior Systems Administrator roles.

The goal of this lab is to demonstrate practical knowledge of user account support, password resets, MFA support, Outlook troubleshooting, mailbox support, Microsoft Teams basics, licensing concepts, and clear help desk documentation.

## Skills Demonstrated

- Microsoft 365 admin support concepts
- User account management documentation
- Password reset and account recovery workflows
- MFA troubleshooting and reset documentation
- Outlook and mailbox troubleshooting
- Microsoft Teams support basics
- Licensing and access troubleshooting
- Help desk ticket documentation
- Customer-focused technical communication

## Repository Structure

| Folder | Purpose |
|---|---|
| `docs/` | Technical notes and support documentation |
| `checklists/` | Step-by-step support checklists |
| `tickets/` | Realistic help desk ticket examples |

## Example Support Areas

- User cannot sign in
- Password reset request
- Account lockout
- MFA device changed or lost
- Outlook profile issue
- Mailbox access issue
- Shared mailbox access request
- Microsoft Teams audio/video issue
- Missing Microsoft 365 license
- Basic user onboarding support

## Disclaimer

This is a learning and documentation lab. It does not contain real company data, real user information, passwords, credentials, tenant details, or private information.
