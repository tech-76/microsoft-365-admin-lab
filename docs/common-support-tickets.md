# Common Microsoft 365 Support Tickets

## Purpose

This document lists common Microsoft 365 support ticket types and example troubleshooting approaches.

## Ticket Type: User Cannot Sign In

### Possible Causes

- Incorrect password
- Account locked
- MFA issue
- Account disabled
- License issue
- Browser cache problem

### Support Steps

1. Verify user identity.
2. Confirm error message.
3. Check if account is locked or disabled.
4. Reset password if approved.
5. Confirm MFA status.
6. Test sign-in again.

## Ticket Type: Outlook Not Syncing

### Possible Causes

- Network issue
- Outlook profile corruption
- Large mailbox
- Cached mode issue
- Password or MFA prompt
- Service issue

### Support Steps

1. Confirm Outlook web access.
2. Restart Outlook.
3. Check network connection.
4. Confirm mailbox storage.
5. Create a new profile if required.
6. Escalate if multiple users are affected.

## Ticket Type: MFA Reset

### Possible Causes

- New phone
- Lost device
- Deleted Authenticator app
- SMS not working
- Account security change

### Support Steps

1. Verify identity.
2. Confirm device change.
3. Reset MFA registration if authorized.
4. Guide user through new setup.
5. Confirm successful sign-in.

## Ticket Type: Shared Mailbox Access

### Possible Causes

- Missing permissions
- User not added to correct group
- Outlook not refreshed
- Incorrect mailbox name

### Support Steps

1. Confirm approval.
2. Confirm mailbox name.
3. Confirm required access level.
4. Add permission if authorized.
5. Ask user to restart Outlook.
6. Confirm access.

## Ticket Type: Teams Audio Issue

### Possible Causes

- Wrong audio device selected
- Microphone permission blocked
- Driver issue
- Browser permission issue
- Teams cache issue

### Support Steps

1. Confirm device works outside Teams.
2. Check Teams device settings.
3. Check operating system permissions.
4. Test Teams web.
5. Restart Teams or computer.
