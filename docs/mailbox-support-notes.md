# Mailbox Support Notes

## Purpose

Mailbox support includes helping users access, send, receive, organize, and manage email. It may also include shared mailbox access, mailbox permissions, storage issues, and delivery problems.

## Common Mailbox Issues

- User cannot access mailbox
- Mailbox is full
- User cannot send email
- User cannot receive email
- Shared mailbox not visible
- User needs access to shared mailbox
- Deleted email recovery request
- Distribution list issue
- Email stuck in outbox
- Attachment size issue

## Basic Mailbox Checks

- Confirm the user has an active Microsoft 365 license.
- Confirm the mailbox exists.
- Confirm the user can sign in.
- Test Outlook on the web.
- Check mailbox storage usage.
- Confirm shared mailbox permissions.
- Confirm whether the issue affects one user or multiple users.
- Review error messages or non-delivery reports.

## Shared Mailbox Access Workflow

1. Confirm request approval.
2. Confirm the shared mailbox name.
3. Confirm the user who needs access.
4. Confirm access type required.
5. Apply the correct permission if authorized.
6. Ask user to restart Outlook.
7. Confirm mailbox appears.
8. Document completion in the ticket.

## Access Types

| Access Type | Description |
|---|---|
| Full Access | Allows the user to open and manage mailbox content |
| Send As | Allows the user to send as the shared mailbox |
| Send on Behalf | Allows the user to send on behalf of the mailbox |

## Example Resolution Note

Verified manager approval for shared mailbox access. Added user to the approved mailbox permission group and confirmed mailbox appeared after Outlook restart.
