# Microsoft 365 Licensing Basics

## Purpose

Microsoft 365 licenses control which services and applications a user can access. Help desk teams may help identify missing licenses, incorrect license assignments, or access problems related to licensing.

## Common Licensing Issues

- User cannot access Outlook
- User cannot use Office apps
- User cannot access Teams
- User mailbox not created
- User missing OneDrive access
- User cannot install Office apps
- New user account does not have required services
- License was removed by mistake

## Basic Licensing Checks

- Confirm the user account is active.
- Confirm the correct license is assigned.
- Confirm required services are enabled.
- Confirm the user is signing in with the correct account.
- Confirm the issue is not caused by password or MFA.
- Confirm whether the issue affects one user or multiple users.

## Example Licensing Workflow

1. Review the user request.
2. Confirm manager or authorized approval.
3. Check the user's assigned license.
4. Assign the correct license if approved.
5. Confirm required services are enabled.
6. Ask the user to sign out and sign back in.
7. Confirm access is working.
8. Document the change.

## Security and Cost Notes

- Assign only the license needed for the role.
- Remove licenses during offboarding.
- Do not assign licenses without approval.
- Keep ticket notes clear for audit history.
- Escalate unusual license requests.

## Example Ticket Note

User was unable to access Outlook because no Microsoft 365 license was assigned. Confirmed approval, assigned the correct license, and user confirmed mailbox access after signing back in.
