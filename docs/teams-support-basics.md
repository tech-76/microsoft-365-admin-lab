# Microsoft Teams Support Basics

## Purpose

Microsoft Teams is commonly used for meetings, chat, calls, collaboration, and file sharing. Help desk teams support users with sign-in, audio/video, meeting access, notifications, and basic application issues.

## Common Teams Issues

- User cannot sign in
- Microphone not working
- Camera not working
- Audio device not detected
- User cannot join meeting
- Screen sharing not working
- Notifications not appearing
- Teams is slow or frozen
- User cannot access a team or channel
- Files not syncing or opening

## Basic Troubleshooting Questions

- Is the issue on desktop, web, or mobile?
- Can the user access Teams in a browser?
- Is the correct microphone or camera selected?
- Did the user recently change devices?
- Is the user signed in with the correct account?
- Does the user have permission to access the team or channel?
- Is the issue affecting one meeting or all meetings?

## Basic Troubleshooting Steps

1. Restart Teams.
2. Sign out and sign back in.
3. Test Teams web version.
4. Check microphone and camera permissions.
5. Confirm the correct audio/video devices are selected.
6. Restart the computer.
7. Check for updates.
8. Clear cache if required by support procedure.
9. Escalate if issue affects multiple users.

## Example Ticket Note

User reported microphone not working in Teams meetings. Confirmed device worked in system settings. Updated Teams audio device selection and tested in a meeting. User confirmed microphone was working.
