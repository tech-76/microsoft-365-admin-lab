# User Account Management

## Purpose

User account management is a common Microsoft 365 support task. Help desk and IT support teams assist with account creation, sign-in issues, account updates, password resets, MFA support, licensing, and access requests.

## Common User Account Tasks

- Create new user accounts
- Update user display names or contact details
- Assign or remove Microsoft 365 licenses
- Reset user passwords
- Assist with account lockouts
- Review sign-in issues
- Support MFA registration
- Disable accounts during offboarding
- Confirm group or mailbox access

## New User Account Request Information

A standard new user request should include:

- Full name
- Job title
- Department
- Manager
- Start date
- Required email address
- Required Microsoft 365 license
- Required groups
- Required shared mailbox access
- Required applications
- Approval from manager or authorized requester

## Basic Support Workflow

1. Confirm the request is approved.
2. Confirm the user information is complete.
3. Create or update the account.
4. Assign the correct license.
5. Add the user to required groups.
6. Confirm email and sign-in access.
7. Document the completed action in the ticket.
8. Notify the requester.

## Security Considerations

- Never share passwords in plain text.
- Verify the request before making account changes.
- Follow the principle of least privilege.
- Disable unused or inactive accounts.
- Document all account changes.
- Escalate unusual or suspicious sign-in activity.

## Example Ticket Note

User account created for new employee. Microsoft 365 license assigned, temporary password generated according to policy, and user added to required groups. User advised to change password at first sign-in and complete MFA registration.
