# Password Reset Process

## Purpose

Password reset requests are common in help desk support. A clear process helps protect the user account while restoring access quickly.

## Common Reasons for Password Resets

- User forgot password
- Password expired
- Account locked after failed sign-in attempts
- User cannot access Microsoft 365 services
- New employee needs first-time access
- User suspects account compromise

## Password Reset Workflow

1. Confirm the user's identity according to company procedure.
2. Review the ticket details and issue description.
3. Check whether the account is locked or disabled.
4. Reset the password if appropriate.
5. Require the user to change the temporary password at next sign-in.
6. Confirm the user can sign in.
7. Confirm MFA registration if required.
8. Document the resolution.

## Identity Verification Examples

Depending on company policy, verification may include:

- Employee ID
- Manager confirmation
- Approved ticket request
- Phone call to known company number
- Security questions
- Internal HR or directory confirmation

## Security Notes

- Do not send passwords through unsecured channels.
- Do not reset passwords without verifying the requester.
- Escalate suspected compromise.
- Encourage strong passwords and MFA.
- Avoid reusing temporary passwords.
- Record the action in the ticket.

## Example Resolution Note

Verified user identity according to support procedure. Reset password and required password change at next sign-in. User successfully signed in and confirmed access to Microsoft 365 services.
