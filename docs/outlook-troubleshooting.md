# Outlook Troubleshooting

## Purpose

Outlook support is a common responsibility for IT Support and Service Desk roles. Issues may involve sign-in problems, profile corruption, mailbox access, synchronization errors, search problems, or email delivery issues.

## Common Outlook Issues

- Outlook will not open
- User cannot sign in
- Outlook keeps asking for password
- Email not sending or receiving
- Mailbox not syncing
- Shared mailbox not appearing
- Outlook is slow
- Search is not working
- User gets certificate or connection warnings
- Attachments will not open

## Initial Troubleshooting Questions

- Is the issue affecting Outlook desktop, Outlook web, or both?
- Is the user connected to the internet?
- Can the user sign in through the browser?
- Is the issue affecting one user or multiple users?
- Did the issue start after a password change?
- Did the user recently change devices?
- Is the mailbox full?
- Are there any error messages?

## Basic Troubleshooting Steps

1. Confirm internet connectivity.
2. Confirm the user can sign in to Microsoft 365 online.
3. Restart Outlook.
4. Restart the computer.
5. Check for password or MFA prompts.
6. Test Outlook on the web.
7. Check mailbox storage.
8. Rebuild or create a new Outlook profile if needed.
9. Escalate if the issue appears tenant-wide or server-side.

## Outlook Profile Rebuild Notes

A new Outlook profile may help when:

- Outlook will not open properly
- The mailbox does not sync
- The user gets repeated credential prompts
- Search or folders behave incorrectly
- The local profile appears corrupted

## Example Resolution Note

Confirmed user could access Outlook on the web. Outlook desktop profile appeared corrupted. Created a new Outlook profile, added the user's mailbox, and confirmed mail was syncing successfully.
