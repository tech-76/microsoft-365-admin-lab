# Ticket: Microsoft 365 Password Reset

## Ticket Summary

User cannot sign in to Microsoft 365 and requested a password reset.

## User Impact

User is unable to access Outlook, Teams, OneDrive, and other Microsoft 365 services.

## Reported Issue

User reported that their password was not accepted when signing in. User attempted multiple times and could not access email.

## Troubleshooting Steps

1. Verified user identity according to support procedure.
2. Confirmed the issue affected Microsoft 365 sign-in.
3. Checked account status.
4. Confirmed account was active.
5. Reset the password according to policy.
6. Required password change at next sign-in.
7. Asked user to sign in with temporary password.
8. Confirmed user completed password change.
9. Confirmed Outlook and Teams access were restored.

## Resolution

Password was reset successfully. User changed password at next sign-in and confirmed access to Microsoft 365 services.

## Customer Communication

Your password has been reset. Please sign in using the temporary password provided through the approved process, then create a new password when prompted.

## Final Ticket Note

Verified identity, reset Microsoft 365 password, required password change at next sign-in, and confirmed successful access to Outlook and Teams.
