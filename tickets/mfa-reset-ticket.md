# Ticket: MFA Reset

## Ticket Summary

User changed phones and could not approve Microsoft 365 MFA prompts.

## User Impact

User could not access Microsoft 365 services because sign-in required MFA approval on the old device.

## Reported Issue

User reported that they replaced their mobile phone and no longer had access to Microsoft Authenticator on the previous device.

## Troubleshooting Steps

1. Verified user identity according to support procedure.
2. Confirmed user changed phones.
3. Confirmed the user could not approve MFA prompts.
4. Reviewed available MFA methods.
5. Reset MFA registration according to approved process.
6. Guided user through adding the new phone to Authenticator.
7. Confirmed user completed MFA setup.
8. Confirmed successful Microsoft 365 sign-in.

## Resolution

MFA registration was reset and user successfully registered the new device.

## Customer Communication

Your MFA setup has been reset. Please complete the new registration process using your current phone and confirm that you can sign in successfully.

## Final Ticket Note

Verified identity, reset MFA registration, guided user through new Authenticator setup, and confirmed access restored.
