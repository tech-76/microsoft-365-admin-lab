# Ticket: Shared Mailbox Access Request

## Ticket Summary

User requested access to a shared mailbox.

## User Impact

User needed shared mailbox access to review and respond to department email.

## Reported Issue

Manager submitted a request for the user to access a shared mailbox. The user could not see the mailbox in Outlook.

## Troubleshooting Steps

1. Reviewed access request.
2. Confirmed manager approval.
3. Confirmed shared mailbox name.
4. Confirmed user account.
5. Confirmed required access type.
6. Added approved mailbox permission.
7. Asked user to restart Outlook.
8. Confirmed shared mailbox appeared.
9. Confirmed user could open the mailbox.

## Resolution

Shared mailbox access was granted and confirmed working.

## Customer Communication

Shared mailbox access has been added. Please restart Outlook. The mailbox may take some time to appear depending on the environment.

## Final Ticket Note

Verified approval, added user to shared mailbox access, user restarted Outlook, and mailbox appeared successfully.
