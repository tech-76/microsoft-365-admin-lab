# Ticket: Outlook Profile Rebuild

## Ticket Summary

User reported that Outlook desktop was not syncing email properly.

## User Impact

User could access Outlook on the web but could not reliably send or receive email through Outlook desktop.

## Reported Issue

User stated that Outlook desktop was slow, folders were not updating, and new email was not appearing. Outlook web worked normally.

## Troubleshooting Steps

1. Confirmed internet connectivity.
2. Confirmed user could access Outlook on the web.
3. Restarted Outlook.
4. Restarted the workstation.
5. Confirmed the issue was limited to Outlook desktop.
6. Checked for repeated password or MFA prompts.
7. Created a new Outlook profile.
8. Added the user's mailbox to the new profile.
9. Confirmed mailbox synchronization.
10. Sent a test email and confirmed it was received.

## Resolution

Created a new Outlook profile and confirmed email synchronization was restored.

## Customer Communication

A new Outlook profile was created to replace the corrupted profile. Your mailbox is now syncing and test email was successful.

## Final Ticket Note

Issue isolated to Outlook desktop profile. Created new profile, reconnected mailbox, tested send/receive, and confirmed issue resolved.
