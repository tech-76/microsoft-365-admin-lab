# Outlook Issue Checklist

## Purpose

Use this checklist for Outlook desktop, Outlook web, mailbox sync, and email access issues.

## Initial Questions

- [ ] Is the issue with Outlook desktop, Outlook web, or both?
- [ ] What error message appears?
- [ ] When did the issue start?
- [ ] Is the user connected to the internet?
- [ ] Can the user sign in to Microsoft 365 online?
- [ ] Did the user recently change their password?
- [ ] Did the user recently change MFA settings?
- [ ] Is the issue affecting one user or multiple users?

## Basic Troubleshooting

- [ ] Restart Outlook
- [ ] Restart the computer
- [ ] Confirm internet connection
- [ ] Test Outlook on the web
- [ ] Check sign-in credentials
- [ ] Check MFA prompts
- [ ] Check mailbox storage
- [ ] Check for stuck emails in Outbox
- [ ] Confirm Outlook is updated if applicable

## Profile Troubleshooting

- [ ] Confirm issue appears local to Outlook desktop
- [ ] Create a new Outlook profile if needed
- [ ] Add the mailbox to the new profile
- [ ] Confirm mail syncs
- [ ] Confirm calendar and contacts if needed
- [ ] Confirm user can send and receive email

## Escalation Triggers

- [ ] Multiple users affected
- [ ] Possible Microsoft 365 service issue
- [ ] Mail flow issue
- [ ] Missing license
- [ ] Permission issue
- [ ] Data loss concern

## Ticket Closure

- [ ] Root cause or likely cause documented
- [ ] Steps taken documented
- [ ] User confirmed issue resolved
