# Account Lockout Checklist

## Purpose

Use this checklist when a user reports that their Microsoft 365 account is locked or they cannot sign in after multiple attempts.

## Initial Questions

- [ ] What error message does the user see?
- [ ] When did the issue start?
- [ ] Is the issue happening on one device or multiple devices?
- [ ] Did the user recently change their password?
- [ ] Did the user recently change phones or MFA method?
- [ ] Is the user able to sign in through a browser?
- [ ] Is the user connected to the internet?

## Verification

- [ ] User identity verified
- [ ] Ticket request reviewed
- [ ] Account status checked
- [ ] Lockout status checked
- [ ] MFA status checked if applicable

## Troubleshooting

- [ ] Ask user to stop repeated sign-in attempts
- [ ] Reset password if approved
- [ ] Require password change at next sign-in
- [ ] Confirm old password is removed from saved devices
- [ ] Check Outlook, mobile email, and other apps for saved old password
- [ ] Confirm user can sign in successfully
- [ ] Confirm MFA prompt works

## Escalation Triggers

- [ ] Suspicious sign-in activity
- [ ] Repeated lockouts after password reset
- [ ] Possible compromised account
- [ ] Multiple users affected
- [ ] Admin permissions involved

## Ticket Closure

- [ ] Resolution documented
- [ ] User confirmed access restored
- [ ] Security concern escalated if needed
