# MFA Issue Checklist

## Purpose

Use this checklist when a user cannot complete MFA sign-in or needs MFA reset support.

## Initial Questions

- [ ] Is the user using Microsoft Authenticator, SMS, phone call, or another method?
- [ ] Did the user change phones?
- [ ] Was the Authenticator app removed?
- [ ] Is the phone connected to the internet?
- [ ] Is the phone number still active?
- [ ] Is the user receiving any prompts?
- [ ] Is there an error message?
- [ ] Is the issue happening on all sign-ins or one application?

## Verification

- [ ] User identity verified
- [ ] Ticket request reviewed
- [ ] MFA reset request approved if required
- [ ] Suspicious activity reviewed if applicable

## Troubleshooting

- [ ] Confirm correct account is being used
- [ ] Confirm device date and time are correct
- [ ] Ask user to try another available MFA method
- [ ] Reset MFA registration if authorized
- [ ] Guide user through new MFA setup
- [ ] Confirm successful sign-in
- [ ] Confirm backup method is added if policy allows

## Escalation Triggers

- [ ] User did not request MFA change
- [ ] Suspicious login attempts
- [ ] Executive or privileged account
- [ ] Repeated MFA failures
- [ ] User reports unexpected MFA prompts

## Ticket Closure

- [ ] MFA method updated
- [ ] User confirmed access restored
- [ ] Security concerns escalated if needed
- [ ] Ticket notes completed
