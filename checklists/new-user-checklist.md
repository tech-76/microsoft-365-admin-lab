# New User Checklist

## Purpose

Use this checklist when documenting a Microsoft 365 new user setup request.

## Request Information

- [ ] Full name provided
- [ ] Job title provided
- [ ] Department provided
- [ ] Manager provided
- [ ] Start date provided
- [ ] Username or email format confirmed
- [ ] License requirement confirmed
- [ ] Group access confirmed
- [ ] Shared mailbox access confirmed
- [ ] Approval received

## Account Setup

- [ ] User account created
- [ ] Display name confirmed
- [ ] Email address confirmed
- [ ] Temporary password created according to policy
- [ ] User required to change password at first sign-in
- [ ] Correct license assigned
- [ ] Required services enabled
- [ ] MFA registration requirement confirmed

## Access Setup

- [ ] Security groups assigned
- [ ] Distribution groups assigned
- [ ] Shared mailbox permissions assigned if approved
- [ ] Teams access confirmed if required
- [ ] OneDrive/SharePoint access confirmed if required

## Final Checks

- [ ] Test sign-in completed or ready for user
- [ ] User instructions provided
- [ ] Ticket updated with completed actions
- [ ] Requester notified
- [ ] No passwords or private data included in ticket notes
